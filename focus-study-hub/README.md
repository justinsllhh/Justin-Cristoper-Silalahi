# ⏱️ FocusStudy Hub - Smart Pomodoro, Kanban & Ambient Study

**FocusStudy Hub** adalah platform produktivitas lengkap yang dirancang khusus untuk pelajar dan mahasiswa guna memaksimalkan efisiensi belajar, mengelola tugas sekolah, dan mempertahankan fokus mendalam.

---

## 🌟 Fitur Utama
1. **Smart Pomodoro Timer**:
   - Mode Fokus 25 Menit, Istirahat Pendek 5 Menit, dan Istirahat Panjang 15 Menit.
   - Ring visual progress countdown lingkaran SVG yang halus.
   - Integrasi langsung dengan tugas aktif dari papan Kanban.
2. **Papan Tugas Kanban (Task Board)**:
   - 3 Kolom: *Daftar Tugas (To-Do)*, *Sedang Dikerjakan (In-Progress)*, dan *Selesai (Done)*.
   - Tag mata pelajaran (Matematika, Fisika, Biologi, Informatika, Bahasa), prioritas urgensi, dan estimasi beban sesi Pomodoro.
3. **Synthesizer Suara Ambient Belajar**:
   - *Hujan Rintik Alami (Pink noise)*
   - *Gelombang Otak Alpha 10 Hz (Binaural Beats)*
   - *White Noise Murni*
   - *Harmoni Meditasi Solfeggio 528 Hz*
   - Dihasilkan murni secara realtime oleh Web Audio API tanpa perlu memutar file audio luar.
4. **Catatan Cepat (Scratchpad)**:
   - Area pencatatan materi dan ringkasan rumus dengan auto-save otomatis ke LocalStorage.
5. **Statistik Belajar**:
   - Akumulasi total menit fokus, jumlah sesi tuntas, dan persentase penyelesaian tugas.

---

## 🚀 Cara Menjalankan
1. Masuk ke folder `focus-study-hub`.
2. Buka `index.html` pada browser Anda.
