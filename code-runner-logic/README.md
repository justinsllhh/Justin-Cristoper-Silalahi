# 🤖 CodeBot Logic Runner - Game Algoritma & Logika Pemrograman

**CodeBot Logic Runner** adalah game edukasi interaktif berbasis logika pemrograman dan berpikir komputasional (*computational thinking*). Pemain menyusun blok instruksi algoritma untuk menggerakkan karakter robot CodeBot mengarungi rintangan, mengumpulkan energi, membuka saklar, dan mencapai portal tujuan.

---

## 🌟 Fitur Utama
1. **Penyusunan Blok Perintah Visual**:
   - `Maju 1 Langkah`
   - `Putar Kiri 90°` & `Putar Kanan 90°`
   - `Ambil Energi (⚡)` & `Tekan Saklar Gerbang (🔘)`
   - `Pengulangan Loop 2x & 3x`
2. **Virtual Machine Eksekusi Real-Time**:
   - Menjalankan instruksi baris per baris dengan highlight animasi pada daftar kode.
   - Pengatur kecepatan eksekusi (Cepat, Normal, Lambat).
3. **8 Level Tantangan Progresif**:
   - Dari konsep sekuensial sederhana, penghindaran rintangan, pengumpulan variabel energi, struktur loop, hingga logika saklar pintu terkunci.
4. **Konsol & Log Sensor Robot**:
   - Terminal interaktif menampilkan koordinat dan status eksekusi.
5. **Efek Audio Robotik**:
   - Sintesis Web Audio API murni untuk langkah, putaran, tabrakan, saklar, dan kemenangan.

---

## 🚀 Cara Menjalankan
1. Masuk ke folder `code-runner-logic`.
2. Buka `index.html` langsung di browser Anda.
