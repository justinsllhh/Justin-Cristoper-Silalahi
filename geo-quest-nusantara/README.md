# 🗺️ GeoQuest Nusantara - Petualangan Peta & Budaya Indonesia

**GeoQuest Nusantara** adalah game edukasi geografi dan budaya nusantara interaktif yang mengajak pelajar mengenal kepulauan Indonesia, provinsi, landmark sejarah, rumah adat, serta flora & fauna endemik.

---

## 🌟 Fitur Utama
1. **Ekspedisi Peta Nusantara (Interactive Vector Map)**:
   - Menemukan lokasi pulau-pulau besar (Sumatera, Jawa, Kalimantan, Sulawesi, Bali & Nusa Tenggara, Maluku, Papua).
   - Dilengkapi timer, combo multiplier skor, dan fakta sejarah/geografi setiap daerah.
2. **Kuis Warisan Budaya & Tradisi**:
   - Soal interaktif tentang rumah adat (Tongkonan, Honai, Gadang), tarian daerah, senjata pusaka (Rencong, Keris), dan alat musik (Sasando, Gamelan).
   - Penjelasan edukatif lengkap di setiap akhir pertanyaan.
3. **Ensiklopedia Kepulauan**:
   - Menjelajahi luas area, satwa langka khas (Komodo, Orangutan, Cendrawasih, Anoa), dan situs warisan dunia UNESCO.
4. **Ruang Penghargaan (Badges & Titles)**:
   - Gelar penjelajah dinamis dari *Pelaut Pemula* hingga *Laksamana Samudra Nusantara*.
5. **Efek Audio Gamelan Sintesis**:
   - Alunan nada gamelan pentatonis sintetis menggunakan Web Audio API murni.

---

## 🚀 Cara Menjalankan
1. Masuk ke folder `geo-quest-nusantara`.
2. Buka `index.html` pada peramban web modern Anda.
