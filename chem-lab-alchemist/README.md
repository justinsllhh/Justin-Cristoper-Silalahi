# ⚗️ ChemLab Alchemist - Game Reaksi Kimia & Molekul

**ChemLab Alchemist** adalah game edukasi kimia interaktif di mana pemain berperan sebagai ilmuwan laboratorium yang bereksperimen menggabungkan unsur-unsur tabel periodik untuk mensintesis molekul dan senyawa baru.

---

## 🌟 Fitur Utama
1. **Meja Reaksi Interaktif (Lab Beaker)**:
   - Pilih unsur kimia dari rak (Non-logam, Logam, Halogen, Alkali).
   - Masukkan ke dalam tabung reaksi beranimasi cair & partikel dinamis.
   - Uji reaksi kimia dengan animasi letupan partikel dan efek suara Web Audio API.
2. **Misi Penelitian & Quests**:
   - Tantangan menemukan molekul target dari tingkatan dasar (seperti $H_2O$, $CO_2$, $NaCl$) hingga molekul kompleks ($CaCO_3$, $H_2SO_4$, $Fe_2O_3$).
3. **Eksplorasi Tabel Periodik**:
   - Telusuri nomor atom, massa atom relatif, kategori, dan fungsi praktis setiap unsur di dunia nyata.
4. **Jurnal & Ensiklopedia**:
   - Dokumentasi lengkap molekul yang telah berhasil disintesis pemain.
5. **Penyimpanan Lokal (LocalStorage)**:
   - Level, XP, dan riwayat penemuan tersimpan otomatis di browser tanpa instalasi database.

---

## 🚀 Cara Menjalankan
1. Buka folder `chem-lab-alchemist`.
2. Buka berkas `index.html` langsung di browser favorit Anda (Google Chrome, Edge, Firefox, Safari).
3. Tidak membutuhkan instalasi server maupun koneksi internet luar.
